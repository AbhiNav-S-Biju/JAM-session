"File not accessible" on the real card? The page doesn't exist until you generate it. Run this once from the repo folder (use your own subnet; for Wi-Fi at home it is often 192.168.0.0/24):
python -m real.main --quick --subnet 192.168.0.0/24 --i-own-this-network
then reload. See real/README.md.
